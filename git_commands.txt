mkdir GitWorkflowAssignment
Creates the project directory.

cd GitWorkflowAssignment
Moves into the project directory.

cat > index.html
Creates the homepage HTML file.

cat > about.html
Creates the about page HTML file.

git init -b main
Initializes a Git repository with main as the initial branch.

git status
Displays the current repository state.

git add index.html about.html
Stages the HTML files for committing.

git commit -m "Initial commit: Add website HTML files"
Records the initial project version.

git add about.html
Stages the modified about page.

git commit -m "Update about page with additional content"
Records the second version of the project.

git branch feature
Creates a new branch named feature.

git switch feature
Switches to the feature branch.

git add index.html
Stages the modified homepage.

git commit -m "Add navigation feature to home page"
Records the feature branch changes.

git switch main
Returns to the main branch.

git merge feature
Merges feature branch changes into main.

git log --oneline --graph --decorate --all
Displays commit history, branches and merge relationships.

git remote add origin https://github.com/Advita9/GitWorkflowAssignment.git
Connects the local repository to GitHub.

git push -u origin main
Pushes main to GitHub and configures upstream tracking.

git push -u origin feature
Pushes the feature branch to GitHub.

git status --ignored
Displays ignored files and repository status.

git add .gitignore
Stages the Git ignore configuration.

git commit -m "Add gitignore for log files and temp directory"
Records the ignore configuration.

git add about.html
Stages the temporary paragraph added to the about page.

git commit -m "Add temporary paragraph to about page"
Creates the commit used to demonstrate undo.

git revert --no-edit HEAD
Reverts the most recent commit without rewriting history.

git remote -v
Displays the configured remote repository URLs.

git push origin main
Pushes the latest main branch commits to GitHub.
